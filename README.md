# By-ART Web (GitHub Pages)

เว็บไซต์สำหรับม็อดภาษาไทย/แพ็กเกจ/ดาวน์โหลด โดย By-ART — พร้อมใช้งานบน GitHub Pages (static)

## หน้าเว็บ
- `index.html` — หน้าหลัก, ลิงก์ดาวน์โหลด (ตัวติดตั้ง `.zip`, MEGA ครบทุกอย่างราคาถูกลง, Steam)
- `pricing.html` — แพ็กเกจ (7/14/30 วัน, ถาวร), ชำระเงิน, **แนบสลิปการโอน** และส่งคำสั่งซื้อ (รอตรวจสอบ)
- `login.html` — เข้าสู่ระบบ / สมัครสมาชิก (เดโมในเบราว์เซอร์; พร้อมต่อ backend จริง)
- `account.html` — สถานะบัญชี/สิทธิ์/ช่วงทดลอง 3 วัน/คำสั่งซื้อและสลิป
- `admin.html` — ตรวจสอบและอนุมัติ/ปฏิเสธสลิป (เดโมในเบราว์เซอร์; สำหรับจริงให้ใช้หลังบ้านที่ปลอดภัย)

## โหมดปัจจุบัน (ใช้งานได้ทันทีบน GitHub Pages)
- สมัคร/ล็อกอิน, ทดลอง 3 วัน, แพ็กเกจ/คำสั่งซื้อ, แนบสลิป, สถานะรอตรวจสอบ/อนุมัติ ทำงานใน **เบราว์เซอร์เครื่องนี้** (localStorage) เพื่อทดสอบโฟลว์ครบ
- ไม่ใช่บัญชีจริงข้ามอุปกรณ์ และไม่ใช่การยืนยันการโอนเงินจริงอัตโนมัติ

## ระบบหลังบ้าน (จริง) — ยืนยันสลิป/โอนและบัญชีจริง
ดู `SUPABASE_SETUP.md` และ `supabase_schema.sql`
- แนะนำใช้ **Supabase (ฟรี)**: Auth + Database + Storage (เก็บสลิป) แล้วเชื่อม frontend และทำฝั่งแอดมิน/สิทธิ์อย่างปลอดภัย
- **แนบสลิปจริง:** อัปโหลดสลิปเก็บใน Storage และสร้างคำสั่งซื้อ `pending_review`
- **ตรวจสอบ:** แอดมินตรวจสลิปแล้วอนุมัติ/ปฏิเสธและอัปเดตสิทธิ์ (หรือเชื่อม API ตรวจสลิป/ผู้ให้บริการชำระเงิน + webhook เพื่อยืนยันอัตโนมัติ — ต้องสมัครบริการ/คีย์และรันบนเซิร์ฟเวอร์)
- **บังคับสิทธิ์/หมดอายุ/ลบม็อดอัตโนมัติ:** ต้องให้ตัวติดตั้ง/ม็อดตรวจ license กับเซิร์ฟเวอร์ (client-only กันบายพาสไม่ได้)
